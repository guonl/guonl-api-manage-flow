# APIFlow 接口与前端设计

> 后端 REST 约定：前缀 `/api`，统一响应 `Result{code, msg, data}`（code=0 成功）；
> 分页参数 `pageNum/pageSize`，分页响应 `PageResult{total, list}`；未登录返回 401。

---

## 1. 后端 REST 接口清单

### 1.5 调试 `/api/debug`

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/debug/send | 发送请求（代理执行并落历史） |
| GET | /api/debug/template?urlId= | 调试模板（最近一次请求参数） |

调试请求体：
```json
{ "projectId":1, "envId":2, "urlId":10, "method":"POST",
  "url":"{{base}}/order/create", "headers":[{"key":"Content-Type","value":"application/json"}],
  "query":[{"key":"id","value":"1"}], "bodyType":"json", "body":"{...}" }
```
调试响应体：
```json
{ "status":200, "costMs":128, "size":1024,
  "headers":{"Content-Type":"application/json"},
  "body":"{...}", "success":true }
```

## 2. 前端设计（Vue3 SPA）

### 2.1 技术与工程

- Vue 3 + Vite + Element Plus + Axios + ECharts（工作台图表）；hash 路由（免服务端重写规则）。
- 构建产物输出到 `api-manage-admin/src/main/resources/static/`，Boot 直接托管；开发期 Vite devServer proxy → 8081。
- 前端源码目录：`api-manage-admin/frontend/`（不参与后端编译，通过 npm build 同步到 static）。

### 2.2 布局与导航

```
┌──────────────────────────────────────────────────────┐
│ 顶栏：Logo APIFlow ｜ 面包屑 ｜ 环境切换(全局) ｜ AI ⚡ │ 用户▾ │
├──────────┬───────────────────────────────────────────┤
│ 侧边菜单  │  内容区（router-view）                     │
│ 工作台    │                                            │
│ 项目管理  │                                            │
│ API 管理  │   （API 管理/调试/流程为三栏布局：           │
│ 接口调试  │     左树 ｜ 中间主区 ｜ 右侧辅助面板）        │
│ 流程编排  │                                            │
│ AI 助手   │                                            │
│ 系统设置  │                                            │
└──────────┴───────────────────────────────────────────┘
```

### 2.3 页面清单与交互要点

| 路由 | 页面 | 交互要点 |
|---|---|---|
| /login | 登录 | 回车提交；错误 shake 提示 |
| /dashboard | 工作台 | 统计卡片 + 最近调用/运行列表 + 快捷入口 |
| /project | 项目管理 | 表格 + 新建/编辑抽屉；行内「环境」「同步」入口 |
| /project/env | 环境管理 | 项目维度 Tab 切换；Base URL 校验 |
| /project/sync | 同步中心 | 选项目 → 预览 diff（新增/更新/下线三 Tab，勾选确认）→ 应用 |
| /api | API 管理 | 左树（项目/分组/接口，关键字过滤）；中列表；右详情抽屉（参数表/文档 Tab） |
| /debug | 接口调试 | 类 Postman：上（URL+Method+发送）／Tab（Params/Headers/Body）／下（响应 Pretty/Raw/Headers + 状态徽标）；左树选接口自动填充模板 |
| /flow | 流程列表 | 表格 + 运行历史入口 |
| /flow/editor/:id | 流程编辑器 | 左步骤卡列表（拖拽排序）；中步骤配置（请求/提取/断言三 Tab）；右运行面板（步骤结果时间线，失败单步重跑） |
| /flow/run/:runId | 运行详情 | 只读回放：步骤时间线 + 请求/响应/提取/断言明细 |
| /ai | AI 助手 | 对话窗口 + 场景化快捷操作（分析结果/生成流程） |
| /settings | 系统设置 | AI 配置（连通性测试按钮）+ 密码修改 |

### 2.4 关键交互细节

1. **环境切换**：顶栏全局环境选择器（按当前项目过滤），调试/流程默认使用所选环境，存 localStorage。
2. **调试台**：
   - 从 API 树点「调试」→ 携 urlId 跳转 → 自动拉取模板（最近请求参数优先，其次按采集参数生成骨架）；
   - JSON Body 编辑器带格式化按钮与错误提示；
   - 响应 JSON 自动格式化，大响应折叠；状态码徽标绿(2xx)/黄(3xx)/红(4xx,5xx)/灰(异常)；
   - 「存为接口」「发给 AI 分析」按钮置于响应区头部。
3. **流程编辑器**：
   - 步骤卡显示：序号、名称、方法徽标、URL、提取变量数、断言数、启用开关；
   - 卡片间连接线体现顺序；拖拽（HTML5 DnD）改 sort_order；
   - 运行面板时间线：每步状态 icon（成功✓/失败✗/跳过－/运行中 spinner）+ 耗时；点击展开详情抽屉；
   - 失败步骤「单步重跑」按钮；整体「重跑」按钮。
4. **AI 面板**：全局侧滑抽屉（顶栏 ⚡ 打开），任何页面可快速提问；调试页/流程页触发场景化 Prompt 预填。
5. **空态与降级**：AI 未配置显示引导卡片（去设置）；无数据显示插画空态。

### 2.5 状态与请求约定

- Axios 拦截器：统一解析 `code`，401 → 跳登录；非 0 → ElMessage 报错；
- 请求 loading：全局进度条（顶部）+ 按钮级 loading。
