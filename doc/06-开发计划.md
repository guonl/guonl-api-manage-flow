# APIFlow 开发计划

> 原则：小步提交、每阶段可编译验证（`mvn clean compile/package`）、避免一次性大输出。

---

## 阶段 0：工程升级与地基（对应文档 02）

| # | 任务 | 验证 |
|---|---|---|
| 0.1 | 根 pom 升级：Boot 4.1.1 BOM、java 17、模块管理 | mvn validate |
| 0.2 | tools 模块：jakarta 化、PathPatternsRequestCondition、AutoConfiguration.imports、去 fastjson | mvn package（tools） |
| 0.3 | admin 模块：starter-webmvc、MyBatis 4.0.x、mysql-connector-j、HikariCP、去 PageHelper/Druid/Thymeleaf | mvn compile |
| 0.4 | v2 SQL 执行到远程库（新增表 + 增列）；更新 application.yml | 表结构核对 |
| 0.5 | common 层：Result/PageResult/异常处理/AES 工具/BCrypt | compile |
| 0.6 | admin 启动冒烟（依赖登录外放行 /index.html） | 启动日志 + curl |
