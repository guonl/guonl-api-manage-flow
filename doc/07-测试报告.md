## 三、观察项与改进建议

| 编号 | 级别 | 描述 | 建议 |
| --- | --- | --- | --- |
| O-1 | 观察 | NORMAL 模式下存在 CONTINUE 失败步骤时 `runStatus=SUCCESS`（流程「执行完成」与步骤「执行健康」语义分离） | 可保持现状；若需醒目提示，可在运行详情页顶部汇总「N 个步骤失败」徽标（步骤状态已标红） |
| O-2 | 观察 | `status.ready` 语义为「ChatClient 已初始化」，启动后/保存配置后立即查询为 false，易被误读为「配置错误」 | 文档已注明为懒加载；前端设置页以 `configured` + 「测试连通」按钮为准，当前实现正确 |
| O-3 | 提示 | `/api/flow/import` 要求请求体为**纯流程 JSON**（非 ApiResult 包装），直接用 API 调用者传 GET /export 的完整响应会报「流程名称不能为空」 | 前端实现已正确取 data；可在 API 文档中标注示例 |
